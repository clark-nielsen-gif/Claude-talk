Claude Talk bringer Claudes stemme ind i dine Discord-opkald – uden ekko.

**Installér:** hent `ClaudeTalk-Setup.exe`, kør den, og tryk "Sæt det op for mig". Kræver Windows 11 og internet under installationen.

`ClaudeTalk-portable.zip` er selve programmet uden installer. Discords mikrofon skal stadig installeres én gang via `ClaudeTalk-Setup.exe`.

Se README for hjælp og `MANUAL_TEST.md` for en tjekliste til et rigtigt opkald.
